# taro-apps Works

制作実績ページ用の静的サイトです。

## 公開サイト

https://tarowoks-pixel.github.io/portfolio-site/

## 内容

小規模Webサイト制作、LP制作、業務改善ツール、Excel自動化サンプルなどを掲載しているポートフォリオです。
中小企業・個人事業主の方が「少し面倒な作業を減らしたい」と思ったときに相談しやすい内容を意識して作成しています。

## 確認方法

`index.html` をブラウザで開いて確認できます。

## GitHubに慣れていない方へ

このページは、制作したポートフォリオサイトの元データを置いている場所です。

実際のサイトは、以下のURLからご覧いただけます。

https://tarowoks-pixel.github.io/portfolio-site/

GitHubの使い方が分からない場合でも問題ありません。
サイトの内容をご確認いただくだけであれば、上記URLを開いていただければ大丈夫です。

ご相談やご依頼は、ポートフォリオサイト内の「相談する」から、
メール・ココナラ・CrowdWorksのいずれかでご連絡ください。
