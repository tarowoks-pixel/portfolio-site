どんな人向け

テストエンジニア・開発者

テスト設計の経験が浅い人や、テスト観点の抜けを減らしたい人向け。仕様を渡すだけで「何をテストすべきか」を体系的に学べます。

どうやって学ぶ

クイズ形式で反復練習

短い仕様文と選択肢を見て、必要なテスト項目をすべて選ぶ形式。正解・不正解ごとに観点の解説が表示され、繰り返すことで判断力が身につきます。

Technical

使用技術・担当範囲

フレームワーク

Electron

WebアプリをWindows実行ファイルとして配布するためにElectronを使用。インストール不要のポータブル形式で配布。

UIライブラリ

React / TypeScript

問題画面・結果画面・解説画面をReactコンポーネントで構成。TypeScriptで型定義し、問題データのミスを防ぐ構造にした。
