Code

処理の概要

4ステップで表記ゆれ統一→重複検出→マージ→出力まで一括処理します。

01

全角→半角・表記統一

電話番号の全角数字を半角に変換し、ハイフン（ー・－・―）を統一。住所の全角数字・英字も半角化。

def normalize(s):
    # 全角→半角変換
    s = s.translate(ZEN_HAN_TABLE)
    # ハイフン統一
    s = re.sub(r'[ー－―‐−]', '-', s)
    return s.strip()

df["tel"] = df["tel"].apply(normalize)
df["address"] = df["address"].apply(normalize)
02

重複キーの生成

住所と電話番号を組み合わせたキーで重複を検出。一方が欠損している場合は空文字で補完。

df["_key"] = (
    df["address"].fillna("") +
    "_" +
    df["tel"].fillna("")
)

duplicates = df[df.duplicated(
    subset="_key", keep=False
)]
03

重複グループをマージ

同一キーのグループを1行にまとめ、種別（サービス種別等）は「/」結合で保持。確認用の差分ログも出力。

def merge_group(group):
    base = group.iloc[0].copy()
    base["service_type"] = " / ".join(
        group["service_type"]
        .dropna().unique()
    )
    return base

df_clean = (
    df.groupby("_key", group_keys=False)
      .apply(merge_group)
      .drop(columns="_key")
      .reset_index(drop=True)
)
04

CSV出力

全列をダブルクォーテーションで囲み、BOM付きUTF-8でCSV出力。Excelで開いても文字化けしない形式。

df_clean.to_csv(
    "output_clean.csv",
    index=False,
    encoding="utf-8-sig",
    quoting=csv.QUOTE_ALL
)

print(f"完了: {len(df)} 件 → "
      f"{len(df_clean)} 件")
